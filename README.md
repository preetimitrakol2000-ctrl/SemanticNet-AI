# SemanticNet-AI

An in-memory Knowledge Graph representation engine programmed natively in Python. By treating entities as nodes and relationships as directional weighted edges, this library executes semantic inferences and multi-hop paths without wrapping heavy external database libraries.

## 🛠️ Key Architectural Details
* **Adjacency Representation:** Implemented via optimized dictionary mappings.
* **Multi-hop Evaluation:** Recursive route parsing to deduce implied connections.
